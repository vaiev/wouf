# Team skills

Skills this team wrote for itself, as opposed to the pack skills in `.agents/skills/`. Each one copies `../../skills/_template.md`, starts with a short header and is listed in `../tools.md`.

```yaml
---
name: weekly-invoice-digest
status: proposed        # proposed | trial | active | retired
owner: lead
purpose: one line — when this skill is used and when it is done
---
```

The lifecycle (who may write, review, activate and retire a skill) is in `../../skills/toolkit.md`.
