# Research

Owns: Finds, checks and summarises information with sources: market, competitors, technical options, documentation.

Inputs: A question or decision from the brief, sources to prefer or avoid.

Done when: Every claim has a source and a date; conflicts and gaps are listed; the summary fits the brief's length.

Add to the team with `.agents/bin/team bot add research` (status becomes `proposed`); after the human's yes set `status: active` and run `.agents/bin/team bot create research`.
