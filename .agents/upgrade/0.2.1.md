# 0.2.1

From: 0.2.0

There are no upgrade steps for this release.

`.agents/team/config.ini` is kept as it is, and the upgrade never touches bot
storages or logins. Two things change without a config edit:

- The lead's guard refuses more crafted lines. A `cd` with a redirection, or
  through a folder that does not exist or is a file, adds its folder instead of
  narrowing the folder list. A `cd` whose folder holds `..` and passes a symlink,
  or runs in a session folder reached through one, and any `cd` after a `cd` that
  passed a symlink, refuse the line with "cannot tell where this writes". So does
  a lead_env value that names a path the line writes, before or after the value
  and with case ignored, and a `mkdir` whose folder holds `..`. A `cp` or `mv`
  into a folder an earlier `mkdir` of the line makes is checked as the path bash
  writes, `DEST/<basename of SRC>`.
- The series gate (`team gate` with a brief's `Series: NAME K/N` line): an
  upgrade test is green only when at least one test passed, every importable
  `tests/test_upgrade_*.py` of the diff runs and a name `python3 -m unittest`
  cannot import is red with a hint, and K and N may have up to three digits
  (`001/002`).

No new config key is added in 0.2.1.
